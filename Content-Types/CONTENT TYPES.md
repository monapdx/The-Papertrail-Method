


| TYPE                  | DEFINITION                                                              | **CATEGORY**          | PURPOSE                                                                                |
| --------------------- | ----------------------------------------------------------------------- | --------------------- | -------------------------------------------------------------------------------------- |
| **[[EPISODE]]**       | An installment in a show                                                | **[[PUBLICATION]]**   | Provides the transcript for an episode's content                                       |
| **[[FORM]]**          | A web form with input fields + account destination                      | **[[INTERACTIVE]]**   | Collects information from someone                                                      |
| **[[SUBMISSION]]**    | Form input responses sent as an EMAIL                                   | **[[COMMUNICATION]]** | Creates the first EMAIL in a THREAD                                                    |
| **[[EMAIL]]**         | A message that gets sent to a character's ACCOUNT                       | **[[COMMUNICATION]]** | Communication between characters                                                       |
| **[[ACCOUNT]]**       | Email interface belonging to a CHARACTER                                | **[[COLLECTION]]**    | Accept submissions, forward submissions, reply to submissions, internal correspondence |
| **[[THREAD]]**        | A sequence of EMAILS that begin with a SUBMISSION                       | **[[COLLECTION]]**    | Allows readers to see all emails regarding a submission grouped together in sequence   |
| **[[CHAT]]**          | A conversation between characters                                       | **[[COMMUNICATION]]** | A simulated interactive chat conversation between characters                           |
| **[[INTERVIEW]]**     | A type of EPISODE transcript between a HOST and a GUEST                 | **[[PUBLICATION]]**   | Specifies the type of EPISODE by introducing a guest speaker                           |
| **[[ADVERTISEMENT]]** | An advertisement for a business or organization aired during an EPISODE | **[[PUBLICATION]]**   | Establishes a business, organization, product, or service that sponsors the show       |
| **[[FLOWCHART]]**     | An artifact that shows relationships between DECISIONS and OUTCOMES     | **[[ARTIFACT]]**      | Guides the reader through the decision making process of the flowchart author          |
| **[[SPREADSHEET]]**   | An artifact that can contain data entries in a table format             | **[[ARTIFACT]]**      | Allows the reader to see what information is collected and how it is categorized       |
| **[[BUSINESS CARD]]** | An artifact that contains information about a character                 | **[[ARTIFACT]]**      | Establishes character identities and information about their roles                     |
| **[[DOCUMENT]]**      | An general purpose artifact containing any text or content              | **[[ARTIFACT]]**      | Acts as a container for content that isn't specified in any other available format     |
| **[[CHARACTER]]**     | A character in a story                                                  | **[[IDENTITY]]**      | Anchors every artifact and communication to an established identity                    |
| **[[ORGANIZATION]]**  | The fictional organization that your story is told through              | **[[IDENTITY]]**      | The main storytelling engine for the entire method                                     |
